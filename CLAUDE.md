# journal-machinery

Tooling for running Claude Code inside an Obsidian journal (inline `@claude` replies, optional reviews, full-journal chat).

If the user wants this installed into their vault, follow `SETUP.md` step by step. For what each file does, see `README.md`.

Do not run `install.sh` against a vault without first listing its contents and confirming the path with the user. It writes to `~/Library/LaunchAgents`.
